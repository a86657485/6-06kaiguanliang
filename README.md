# 校园开关站 · 第6课《开关量的真与假》

## 启动
- 双击 `启动课堂.command`，或运行 `node --no-warnings server.cjs`（需要 Node ≥ 22.13）。
- 学生访问 `http://教师电脑IP:8798/`。
- 教师大屏访问 `http://localhost:8798/teacher`：免密码，只有教师设备能打开。`/teacher?demo=1` 显示虚构的演示班级。
- 教师测试模式访问 `/test`：可以自由选站，不写入班级数据。

## 名单
- 正式名单放在 `roster.json`，格式同 `roster.example.json`。
- 示例名单（roster.example.json）里都是虚构学生，正式名单不随仓库发布。
- 名单可以用 `tools/import-roster.py` 导入。

## 六站（地图上按顺序拜访 NPC）
1. 监测站门口·指令哪来（目标1·重点）
2. 校园控制室·设备面板（目标1/2·重点）
3. 礼堂举牌台·举牌表决（目标2·重点）
4. 真假问答亭（目标2·重点）
5. 取反实验室（目标3·难点）
6. 统计器工坊·投票统计器（拓展）

最后是出门条：20题考核。

## 规则
- 每站拿到★★才能回地图，可以重做。
- 从第2次尝试起出现“再试一次的小提示”，只给方向，不给答案。
- ★★★要求第一次独立做对。
- 只用鼠标和键盘，不用麦克风，音效默认关闭。

## 奖励小游戏 · 取反闪电站（考核80分解锁）
- 最近一次20题考核达到 80 分才解锁（服务端判定），入口在考核结果页和出门条报告页；`/game` 学生入口，教师测试 `/game-test` 不受分数限制、不写入班级数据。
- 玩法：智能路灯、风扇、水泵、鱼缸加热棒、冰箱提醒器、停车场道闸等场景，传感器给出开关量 A（1/0），按 `F` 输出 0、`J` 输出 1，让设备执行 NOT A。
- 共20题、约1～2分钟；限时从4秒缩到1.6秒，第15题起可能出现 NOT NOT A（取反两次）。
- 成绩由服务端按按键记录重放核算，显示本班排行榜；只用键盘鼠标，音效默认关闭。
